# arsenic-deploy
A deployable version of arsenic for hosting services.

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/new/template?template=https://github.com/smartfoloo/arsenic-deploy)
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/smartfoloo/arsenic-deploy)
[![Deploy to Koyeb](https://www.koyeb.com/static/images/deploy/button.svg)](https://app.koyeb.com/deploy?type=git&repository=github.com/smartfoloo/arsenic-deploy&branch=main&name=arsenic)
[![Deploy to DigitalOcean](https://www.deploytodo.com/do-btn-blue.svg)](https://cloud.digitalocean.com/apps/new?repo=https://github.com/smartfoloo/arsenic-deploy/tree/main)
[![Run on Google Cloud](https://deploy.cloud.run/button.svg)](https://deploy.cloud.run/?git_repo=https://github.com/smartfoloo/arsenic-deploy)
[![Deploy to Heroku](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/smartfoloo/arsenic-deploy)

## Supported Services

- **Railway**
- **Render**
- **Koyeb**
- **DigitalOcean App Platform**
- **Google Cloud Run**
- **Heroku**
- **Fly.io**
- **Northflank**
- **Azure App Service**
- **Gigalixir**
- **Bonto**

## Won't work

- **Vercel**
- **Netlify**
- **Cyclic**
- **AWS App Runner**
- **Fastly Compute**
